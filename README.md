# TIRSO — Firmas de correo

Aplicación estática en HTML, CSS y JavaScript. No requiere compilación ni dependencias.

- index.html: acceso a los dos formatos.
- firmas-completas.html: generador de firmas para Tirso Design y Tirso Lighting.
- firmas-respuesta.html: propuestas compactas en revisión.

## Vercel
Importar el repositorio de GitHub. Framework: Other. Directorio raíz: ./.
Sin Build Command. Directorio de salida: ./.

Las imágenes de los banners siguen alojadas en Milanote. El logo estático de Lighting para la firma abreviada está pendiente del archivo adjunto.

Los datos se procesan en el navegador; no hay backend ni analítica.
